O Ranking Geral é a média da tua posição percentil em cada teste que já fizeste (precisa de pelo menos 2 testes diferentes para aparecer) — método "Total Score of Athleticism" (Turner et al., 2019), adaptado para plantéis pequenos como o nosso: em vez de médias de valores brutos (metros, segundos…, que não dá para comparar entre testes diferentes), usa-se sempre a tua posição relativa em cada um. Testes que ainda não fizeste não entram nem prejudicam a média. Continua sem mostrar nomes/valores das colegas — só a tua posição.
